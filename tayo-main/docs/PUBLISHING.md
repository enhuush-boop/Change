# Publishing TAYO to GitHub

This page lists exactly what belongs in the repository, what must stay out, and
the commands to publish and clone it.

images/models.

## 2. What must stay out

| Path | Why |
|---|---|
| `.venv/` | Platform-specific Python environment; recreate with the setup script. |
| `backend/.env` | Local settings and API keys. Only `.env.example` is committed. |
| `backend/.model_cache/` | Downloaded model weights (hundreds of MB). |
| `benchmark/data/` images | Downloaded datasets; licenses differ and files are large. |
| `benchmark/data/sample.mp4` | Generated by the smoke test. |
| `__pycache__/`, `*.pyc` | Python bytecode. |
| `*.log` | Local logs. |
| Any model weights (`*.safetensors`, `*.bin`, `*.gguf`) | GitHub rejects or discourages large binaries; download on first run. |

The included `.gitignore` already covers all of these.

## 3. Check before committing

```bash
# From the repository root
git init
git add .
git status --short

# No large files should be staged
git ls-files -z | xargs -0 du -h | sort -h | tail -15

# No obvious secrets should be present
git grep -nE 'hf_[A-Za-z0-9]{20,}|AIza[0-9A-Za-z_-]{20,}|sk-[A-Za-z0-9]{20,}'
```

If the last command prints anything, remove the key from the file and rotate it
before pushing.

## 4. Publish

Create an empty repository on GitHub first (do not add a README there), then:

```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/tayo.git
git push -u origin main
```

If you use SSH:

```bash
git remote add origin git@github.com:YOUR_USERNAME/tayo.git
git push -u origin main
```

## 5. What other people run

After cloning:

```bash
git clone https://github.com/YOUR_USERNAME/tayo.git
cd tayo

./scripts/setup_backend.sh
.venv/bin/python scripts/warmup_models.py   # optional, pre-downloads models
./scripts/run_backend.sh
```

Then load the extension:

1. Open `chrome://extensions` (or `edge://extensions`).
2. Enable **Developer mode**.
3. Click **Load unpacked** and select the `extension/` folder.
4. Open the side panel and confirm the status bar says **Local server ready**.

The first image analysis downloads the Smaug detector (~870 MB) and the first
text analysis downloads ModernBERT (~300 MB). The cache is stored in
`backend/.model_cache/` and is reused on later runs. A CPU-only machine works;
expect roughly 2 seconds per image with Smaug's default single-crop mode.

## 6. Optional release artifacts

You can attach a zipped extension to a GitHub Release:

```bash
cd extension
zip -r ../tayo-extension.zip . -x '*.DS_Store'
```

Do **not** commit the zip; attach it to the release instead. Chrome Web Store
submission also requires a privacy policy and a justification for the localhost
host permission.

> Local-first fact-checking and AI-media triage: a Chrome side panel backed by
